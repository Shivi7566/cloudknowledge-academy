Interactive Practice Question Scenario

Domain 2 · Conditional Access & Risk Scenario: Enforcing Zero Trust for Tier-0 Privileged Administrators

Your enterprise requires all Global Administrators to authenticate only from Intune-compliant corporate devices and pass phishing-resistant FIDO2 MFA whenever accessing the Microsoft Entra admin center from an untrusted IP. What is the most resilient architecture?

  • A Create a trusted named IP location and exclude it from MFA requirements entirely.
  • B Configure a Conditional Access policy targeting Directory Roles (Global Admin), cloud app (Azure Portal), grant controls: Phishing-resistant MFA + Require Compliant Device, with session sign-in frequency set to 1 hour.
  • C Enable Security Defaults in the Microsoft Entra tenant and disable legacy authentication protocols.
  • D Assign permanent Global Administrator roles to all IT staff with SMS-based MFA enabled on their personal phones.
ARCHITECTURE RATIONALE:

Option B satisfies the Zero Trust principle "Never Trust, Always Verify". Requiring both Phishing-Resistant MFA (FIDO2 / Certificate-Based) and a Compliant Device prevents adversary-in-the-middle (AiTM) session hijacking and rogue device enrollment. Security Defaults cannot enforce granular phishing-resistant controls.
