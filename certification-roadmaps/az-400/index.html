What this exam is like

Who it's for

Senior engineers and architects.

Prerequisites

Azure Administrator Associate (AZ-104) or Azure Developer Associate (AZ-204 retired Jul 31, 2026 — existing holders still count).

What it tests

Design and implement processes and communications10-15%
Design and implement a source control strategy10-15%
Design and implement build and release pipelines50-55%
Develop a security and compliance plan10-15%
Implement an instrumentation strategy5-10%

Prep roadmap

  1. 1
    Read the study guideWeek 1–2

    Go through the official skills-measured list on Microsoft Learn and tick off each objective.

    ▶ video✎ blog
  2. 2
    Build a labWeek 3–6

    Use a free Azure account or Microsoft 365 trial tenant and practise every objective hands-on.

    ▶ video✎ blog
  3. 3
    Cover the domainsWeek 7–9

    Start with the heaviest domains: Design and implement build and release pipelines and Design and implement processes and communications.

    ▶ video✎ blog
  4. 4
    Practice assessmentWeek 10–12

    Take the free Microsoft Learn practice assessment until you consistently score 80%+.

    ▶ video✎ blog
  5. 5
    Book and sit the exam

    Schedule through Microsoft Learn with Pearson VUE — online proctored from home or at a test centre. Take the free Microsoft Learn practice assessment first.

    ▶ video✎ blog
  6. ✓
    Certified 🎉

    Add it to LinkedIn and your CV — then pick the next step on the certification path.

What you can do after

  • ✓Deploy and manage Azure resources
  • ✓Design secure, reliable Azure solutions
